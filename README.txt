# My PWA (starter)
1) Deploy quickly:
   - Go to https://app.netlify.com/drop
   - Drag this folder (or the ZIP) → you'll instantly get a live link.
2) Or GitHub Pages:
   - Create a repo, push these files to the root branch.
   - Enable Pages in repo Settings → Pages → Branch: main → /(root).
3) Customize:
   - Edit manifest.json (name, colors).
   - Replace /assets/icons with your own PNGs (192 & 512).
   - Bump CACHE_NAME in sw.js when you change assets.
